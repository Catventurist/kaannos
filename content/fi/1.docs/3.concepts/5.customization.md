Kaannos pohjautuu Nuxt 4:n, joka tarjoaa venyvän komponenttikerroksen mahdollistaen tiettyjen ulkoasun komponenttien osien muokkaamisen. Näin on helppoa muokata visuaalista ulkoasua ja sen toimitoja koskematta perusteemaan.

Ohittaaksesi komponentin luo samanniminen Vue-tiedosto `components/`-kansioon. Kaannos käyttää automaattisesti versiotasi oletuksen sijaan.

## Yläpalkki

Voit muokata yläpalkin eri osia ohittamalla komponentteja:

### `AppHeaderLogo`

Vaihtaaksesi oman logon, luo tiedosto `components/AppHeaderLogo.vue`. Tämä korvaa oletuslogon Kaannos-teemasta.

![Yläpalkin logon visuaali](/documentation/app-header-logo.webp){.rounded-lg.border.border-accented.w-full}

::

### `AppHeaderCTA`

Muokataksesi otsikon toimintakehotusta (esim. lisäämällä **Aloitetaan**-painikkeen tai linkin) ohita oletus `components/AppHeaderCTA.vue`-komponentilla.

![App header CTA visuaali](/documentation/app-header-cta.webp){.rounded-lg.border.border-accented.w-full}

::note
---
to: https://github.com/nuxt-content/docus/blob/main/docs/app/components/AppHeaderCTA.vue
---
Oletuksena komponentti on tyhjä, mutta voit ottaa mallia kuinka se ohitetaan Kaannosin dokumentaatiosta.
::

### `AppHeaderCenter`

Yläpalkin keskiosan muuttaminen hoituu `components/AppHeaderCenter.vue`-komponentilla. Se korvaa Kaannos-teeman hakupalkin.

### `AppHeaderBody`

Oletuksena mobiilinäkymässä avautuu `content/`-kansion sisällön valikko käyttäen [ContentNavigation](https://ui.nuxt.com/components/content-navigation)-komponenttia. Voit ohittaa valikon `components/AppHeaderBody.vue`-komponentilla ja täyttää valikon rungon (yläpalkin alla) mobiilinäkymässä.

## Docs

Voit myös muokata ylä- ja sivupalkkeja sisällölle.

### `DocsPageHeaderLinks`

Sivun otsikkopalkin oikeassa reunassa Kaannosin oletus näyttää alasvetovalikon toimintoineen liittyen sivun Markdown-lähteeseen. Se antaa lukijalle mahdollisuuden:

- **Kopioi suora linkki** raakaan `.md`-tiedostoon leikepöydälle.
- **Katsele Markdown-lähdettä** uudessa välilehdessä.

Nämä ovat käteviä osallistujille ja lukijoille, voit luoda omasi `components/DocsPageHeaderLinks.vue`-komponentin avulla.
