Kaannos tarjoaa sisällön asetusten muuttamisen tiedostossa [app.config.ts](https://nuxt.com/docs/guide/directory-structure/app-config).

::warning
Tarvitset tiedoston `nuxt.config.ts` mikäli haluat ohittaa app-asetukset. Ilman Nuxt-asetustiedostoa muutokset eivät päivity.
::

## SEO

Tekninen SEO on haasteellista ja tylsää. Kaannos tarjoaa varman valinnaisen oletusasetelman, joka toimii alusta pitäen antaen täyden hallinnan SEO-metadataan otsikosta someenjakokuviin.

### Metadata

Joustavat `SEO`-metadatan määreet mahdollistavat yleisten tai sivukohtaisten arvojen ohittamiset.

#### Yleisasetukset

Määritä `SEO`-oletusmetat `app.config.ts`-tiedostossa. Näitä arvoja käytetään vararatkaisuina sivuilla, joissa ei ole frontmatteria.

Voit muuttaa myös `site.name`-arvon `nuxt.config.ts`-tiedostossa, oletus perustuu `package.json`-nimeen.

::code-group
```ts [app.config.ts]
export default defineAppConfig({
  seo: {
    // Oletuksena `%s - ${site.name}`
    titleTemplate: '',
    // Oletuksena package.json name
    title: '',
    // Oletuksena package.json description
    description: ''
  },
})
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  site: {
    name: 'Kaannos',
  },
})
```
::

#### Sivukohtaiset asetukset

Jokainen `content/`-kansion Markdown-tiedosto alkaa frontmatter-laatikolla (`---`). Voit määrittää `SEO`-metadatat sivukohtaisesti käyttäen `seo`-avainta:

```md [content/concepts/configuration.md]
---
seo:
  title: 'Asetukset'
  description: 'Muokkaa Kaannos-dokumentaatiota Nuxtin asetustiedostossa.'
---

<!-- Sivun sisältö -->
```

::tip{to="/fi/docs/concepts/edition#frontmatter"}
Lisätietoja frontmatterista muokkausoppaassa.
::

### **Somejako (OG) kuva**

Kun jaa linkin sisällöstä someen tai keskusteluohjelmaan, linkki on **unfurled**, eli se antaa maistiaisen siitä, mitä on linkattu (näyttäen otsikon, kuvauksen ja kuvan). Nämä perustuvat **Open Graph Protocol**:n.

#### Dokumentaatiosivut

Käyttäen [Nuxt OG Image](https://nuxtseo.com/docs/og-image/getting-started/introduction)-moduulia voidaan luoda OG-kuvat jokaiselle sivulle perustuen nimeen ja kuvaukseen. Esimerkiksi tämän sivun OG-kuva on:

![sisältösivun og-kuva](/documentation/og-image-example.png){.rounded-lg}

#### Etusivu

Dokumentaatiosivujen tapaan etusivulla käytetään samaa OG-kuvanluontia nimineen ja kuvauksineen.

![etusivun og-kuva](/documentation/og-image-example.png){.rounded-lg}

Jos haluat muokata etusivun OG-kuvaa, lisää sen **absoluuttinen** polku `seo.ogImage`-avaimeen frontmatterissa.

```md [content/index.md]
---
seo:
  ogImage: '/social-card.png'
---
```

Suositellaan kokoa `1280x640` optimaaliseen näkymään someissa.

::tip
OG-kuvien pitää tulla absoluuttisista URL:sta. Oletuksena sivun URL tulee käyttöönottoalustasta, mutta sen voi ohittaa asettamalla `NUXT_SITE_URL`-ympäristömuuttuja.
::

## Otsikko

Muokkaa sisällön `title` tai `logo`-avaimia:

```ts [app.config.ts]
export default defineAppConfig({
  header: {
    // Nimi jos ei logoa
    title: '',
    // Logon asetukset
    logo: {
      alt: '',
      // Vaalea
      light: '',
      // Tumma
      dark: ''
    },
  },
})
```

## Somelinkit

Lisää somelinkkejä alapalkkiin käyttäen `Record<string, string>`, jossa avain vastaa [Simple Icons](https://simpleicons.org/)-kirjaston kuvaketta.

```ts [app.config.ts]
export default defineAppConfig({
  socials: {
    x: 'https://x.com/nuxt_js',
    discord: 'https://discord.com/invite/ps2h6QT',
    nuxt: 'https://nuxt.com',
  }
})
```

## Sisältöluettelo

Voit muokata oikean sivupalkin sisältöluetteloa.

```ts [app.config.ts]
export default defineAppConfig({
  toc: {
    // Otsikko
    title: 'Tällä sivulla',
    // Alaosio
    bottom: {
      title: 'Yhteisö',
      links: [{
        icon: 'i-lucide-book-open',
        label: 'Nuxt UI',
        to: 'https://ui.nuxt.com/getting-started/installation/nuxt',
        target: '_blank'
      }]
    }
  }
})
```

## Kielet

Yhden kielen sisällölle (ilman `@nuxtjs/i18n`-moduulia) kielen voi määrittää tiedostossa `app.config.ts`:

```ts [app.config.ts]
export default defineAppConfig({
  docus: {
    locale: 'fi', // Oletus: 'en'
  }
})
```

Tämä asettaa kielen:
- UI-komponenttien käännöksiin
- `<html>`-merkin `lang`ja `dir`-ominaisuudet
- Kaannosin omat ulkoasuasetukset

::tip{to="/fi/docs/concepts/internationalization"}
Monikieliselle sisällölle kielen vaihtajalla lue [Kieliopasta](/fi/docs/concepts/internationalization).
::

## GitHub-integraatio

Kaannos lukee `.git/`-kansiosta kirjaston `url` ja `branch`-tiedot:

- GitHub-kuvake ylä-ja alapalkissa
- `Muokkaa tätä sivua` ja `Ilmoita ongelmasta`-linkit sivujen lopussa.

Voit muokata sisällön `url`, `branch` and `rootDir`-avaimia lisäämällä asetuksia tiedostoon `app.config.ts`:

```ts [app.config.ts]
export default defineAppConfig({
  github: {
    url: 'https://github.com/nuxt-content/docus',
    branch: 'main',
    rootDir: 'docs'
  }
})
```

Jos et halua käyttää Githubia, voit asettaa `github`-avaimen `false`:ksi estääksesi integraation.

```ts [app.config.ts]
export default defineAppConfig({
  github: false
})
```

::tip{to="/fi/docs/getting-started/studio"}
Näitä asetuksia voi muuttaa myös Studiomuokkaimesse, kokeile ihmeessä!
::
