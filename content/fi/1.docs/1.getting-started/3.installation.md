## `create-docus` CLI

::steps
### Luo kansio

Käytä `create-docus` terminaalissa luodaksesi uuden projektin:

```bash [Terminal]
npx create-docus my-docs
```

Voit valita kahdesta mallista:
- **`default`**: Perusmalli yhdelle kielelle
- **`i18n`**: Sisältää käännösominaisuudet eri kielille

```bash [Terminal]
# Create with i18n template
npx create-docus my-docs -t i18n
```

Suositellaan `bun`:a paketinhallinnassa.

### Aloita kehityspalvelin

Siirry hakemistoon ja aloita palvelin `dev`-kehitystilassa:

```bash [Terminal]
cd docs
bun dev
```
Paikallinen esikatselu löytyy osoitteesta <http://localhost:3000>

### Kirjoita omia julkaisuja

Siirry [Muokkaamisosioon](/fi/docs/getting-started/concepts/edition) oppiaksesi kuinka kirjoittaa julkaisuja.
::

## Kerrosten integraatiot

Kaannosissa käytetään **Nuxtin kerrospohjaista lähtökohtaa**, jolloin voit laajentaa Kaannos-kerrosta suoraan `nuxt.config.ts`-tiedostossa lisäämällä `extends: ['docus']`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['docus']
})
```

## Muokkaaminen Nuxt Studiolla

::steps
### Luo uusi projekti

`npm create nuxt@latest`

### Lisää Studio

`npx nuxt module add nuxt-studio@beta`

### Kirjoita julkaisuja muokkaimella

Kun kaikki on valmista, voit käyttää esikatselua. 

Voit selata sisältösivuja, muokata tai luoda uusia.
