## `create-nuxt` CLI

::steps
### Luo kansio

Käytä `create nuxt@latest` terminaalissa luodaksesi uuden projektin:

```bash [Terminal]
npm create nuxt@latest
```

Suositellaan `bun`:a paketinhallinnassa.

Paikallinen esikatselu löytyy osoitteesta <http://localhost:3000>

### Kirjoita omia julkaisuja

Siirry [Muokkaamisosioon](/fi/docs/getting-started/concepts/edition) oppiaksesi kuinka kirjoittaa julkaisuja.
::

## Muokkaaminen Nuxt Studiolla

::steps
### Luo uusi projekti

`npm create nuxt@latest`

### Lisää Studio

`npx nuxt module add nuxt-studio`

### Kirjoita julkaisuja muokkaimella

Kun kaikki on valmista, voit käyttää esikatselua. 

Voit selata sisältösivuja, muokata tai luoda uusia.
