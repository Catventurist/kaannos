:br

Betaversio sisältää **TipTap visuaalisen muokkaimen** (oletus), **Monaco koodimuokkaimen** sekä uuden **Lomakepohjaisen muokkaimen** YAML/JSON-tiedostoille. Voit vaihdella niiden välillä milloin vain käyttämällä muokkaimen mallin valitsinta työkalupalkissa.
::

Nuxt Studio tarjoaa monipuolisen työtilan niin kehittäjille kuin sisällöntuottajille, antaen vapauden valita eri muokkaimien välillä:

- [Notion-tyylinen muokkain](#tiptap-visuaalinen-muokkain-markdown-tiedostot) `Markdown`-tiedostoille
- [Lomakepohainen muokkain](#lomakemuokkain) `YAML` and `JSON`-tiedostoille
- [Koodimuokkain](#koodimuokkain) kaikille tiedostoille (edistyneille käyttäjille)

Jokaisella muokkaimella on oma tarkoituksensa. Jotkut tykkäävät visuaalisesta muokkaamisesta, kun toiset pitävät suorasta koodin muokkaamisesta. **Markdown & MDC-syntaksi on lopputuloksena** molemmilla muokkaimilla, saumaton muuntaminen onnistuu visuaalisen ja koodimuokkaimen välillä.

## Muokkainmallin vaihto

Voit vaihtaa visuaalisen ja koodimuokkaimen välillä klikkaamalla **toiminnot-valikkoa** tiedoston otsikkopalkissa (oikea ylänurkka):

- **Visuaalinen tila** - Notion-tyyppinen muokkauskokemus Markdownille ja Lomakemuokkain YAML/JSON-tiedostoille.
- **Kooditila** (Monaco) - Suora Markdown/MDC-syntaksin muokkaus

Mieltymyksesi tallennetaan ja käytetään kaikille tiedostoille.

## TipTap visuaalinen muokkain (`Markdown`-tiedostot)

Tarjoaa modernin Notion-tyylisen muokkauskokemuksen Markdown-sisällölle, pohjautuen tunnettuun [TipTap](https://tiptap.dev/)-muokkaimeen yhdistettynä [Kaannos Muokkaimeen](https://ui.nuxt.com/docs/components/editor).

### Pääominaisuudet

- **Rikas tekstimuokkaus** - Muotoile tekstiä otiskoilla, lihavoimalla, kursivoimalla, yliviivauksella, koodilla, linkeillä yms.
- **MDC-komponenttien tuki** - Lisää ja muokkaa omia Vue-komponentteja suoraan visuaalisessa muokkaimessa
- **Media-integraatio** - Käytä mediavalitsinta lisätäksesi kuvia kirjastostasi
- **Emoji-integraatio** - Kirjoita `:` ja emojin nimi lisätäksesi emojia, tai käytä vinoviivakomentoa `/emoji`
- **Vinoviivakomennot** - Kirjoita `/` avataksesi valikon muotoiluasetukset ja komponentit
- **Vedä ja pudota** - Järjestä sisältökohteet raahaamalla
- **Linkkimuokkain** - Leijuva ponnahdusikkuna sisäisille ja ulkoisille linkeille
- **Työkalurivi** - Kuplatyökalurivi ilmestyy kun valitset tekstiä, tarjoten nopean pääsyn muotoiluasetuksiin
- **Reaaliaikainen muuntaminen** - Muuntaa näppärästi visuaalisen sisällön ja MDC/Markdown-syntaksin

### Vue-komponenttien säädöt

Eräs Tiptap-muokkaimen erottuvista ominaisuuksista on mahdollisuus integroida ja muokata omia Vue-komponentteja suoraan muokkainnäkymässä.

#### Luo ja integroi omia komponentteja

Kehittäjät voivat luoda visuaalisesti monimutkaisia komponentteja ja muokkaimia voidaan käyttää ilman teknistä tietämystä. Visuaalinen muokkain hoitaa komponentti-integraatiot vaivatta.

::steps{level="4"}
#### Luo komponentti

Vue-komponenttien tulee sijaita `/app/components/content`-kansiossa, jotta ne näkyvät Muokkaimessa:

```vue [components/content/HomeFeature.vue]
<template>
  <div class="flex items-start gap-3">
    <div class="flex items-center justify-center border rounded-lg p-1.5">
      <UIcon :name="icon" />
    </div>
    <div class="flex flex-col">
      <h3 class="font-semibold">
        <slot name="title" />
      </h3>
      <span>
        <slot name="description" />
      </span>
    </div>
  </div>
</template>

<script setup lang="ts">
defineProps({
  icon: {
    type: String,
    default: 'i-lucide-cursor-click',
  },
})
</script>
```

#### Käytä Markdownissa käyttäen MDC-syntaksia

Komponentit voidaa integroida käyttämällä [MDC-syntaksia](/fi/docs/essentials/markdown-syntax):

```mdc [content/index.md]
::home-feature
  ---
  icon: i-mdi-vuejs
  ---
  #title
  Upotetu Vue-komponentitEmbedded Vue components
  #description
  Muokkaa osioita ja ominaisuuksia visuaalisella muokkaimella.
::
```

#### Muotoile visuaalisella muokkaimella

Kaikki komponentit `/app/components/content`-kansiossa ovat käytössä automaattisesti:

1. Kirjoita `/` milloin vain muokatessa
2. Etsi komponenttisi listasta
3. Lisää ja muokkaa komponentin osioita suoraan muokkaimessa
4. Ominaisuuksien muokkaus visuaalisella näkymällä **tulollaan**
::

#### Integroi ulkoisen kirjaston komponentteja

Oletuksena komponentit ulkoisista kirjastoista (kuten Kaannos) eivät ilmesty muokkaimen komponenttilistaan. Jotta ne saataisiin näkyviin, ne voidaan asettaa yleiseksi Nuxt-asetuksissa:

```ts
export default defineNuxtConfig({
  hooks: {
    'components:extend': (components) => {
      const globals = components.filter(c => ['UButton', 'UIcon'].includes(c.pascalName))

      globals.forEach(c => c.global = true)
    }
  },
})
```

### Virheenjäljitystila

Ota **virheenjäljitystila** käyttöön alavalikosta nähdäksesi reaaliaikaisen muutoksen:

- TipTap JSON-muoto
- MDC AST
- Lopullinen Markdown-tulos
Tämä on hyödyllistä ymmärtämään, kuinka sisältöä muunnetaan ja vianmääritykset jaetaan.

## Lomakemuokkain

Lomakepohjaista muokkainta käytetään:

- **Frontmatter** `Markdown`-tiedostoissa
- **YAML**-tiedostoissa
- **JSON**-tiedostoissa

Tämä poistaa tarpeen suoralta vuorovaikutukselta monimutkaisissa tiedostosyntakseissa. Sen sijaan lomakkeet luodaan automaattisesti perustuen [kokoelmakaavion](https://content.nuxt.com/docs/collections/define) määritelmiin.

### **Kaavan määritys käyttäen** `zod` Schemaa

::note{to="https://content.nuxt.com/docs/collections/define"}
Lue lisää kokoelmakaavion määritelmistä sille tarkoitetusta kohdasta.
::

Kun `schema`-ominaisuudet on määritelty kokoelmassa, tämä luo vastaavan taulukon muokkaimeen.

::code-group
```ts [content.config.ts]
export default defineContentConfig({
  collections: {
    posts: defineCollection({
      type: 'page',
      source: 'blog/*.md',
      schema: z.object({
        draft: z.boolean().default(false),
        category: z.enum(['Alps', 'Himalaya', 'Pyrenees']).optional(),
        date: z.date(),
        image: z.object({
          src: property(z.string()).editor({ input: 'media' }),
          alt: z.string(),
        }),
        slug: property(z.string()).editor({ hidden: true }),
        icon: property(z.string().optional()).editor({ input: 'icon' }),
        authors: z.array(z.object({
          slug: z.string(),
          username: z.string(),
          name: z.string(),
          to: z.string(),
          avatar: z.object({
            src: z.string(),
            alt: z.string(),
          }),
        })),
      }),
    }),
  },
})
```
::

### **Natiivitulojen yhdistäminen**

Primitiiviset Zod-tyypit yhdistetään automaattisesti asianmukaisiin lomakkeen syötteisiin:

- **String** → Teksti
- **Date** → Pävän valinta :badge[Tulossa]
- **Number** → Nummeron lisäys :badge[Tulossa]
- **Boolean** → Kytkin :badge[Tulossa]
- **Enum** → Alasvetovalikko :badge[Tulossa]
- **Merkkijonojen taulukot** → Lista merkkisyötteistä
- **Objektitaulukot** → Haitari sisältäen upotetun lomakkeen kohteet

### Omien tulojen kartoitukset :badge[Tulossa]

Muokkain ylittää primitiiviset tyypit. Voit muokata lomakekenttiä käyttämällä `editor`-menetelmää, joka laajenee Zod-tyyppeihin metadatoineen tehostaen muokkaimen käyttöliittymää.

Tämä mahdollistaa omien tulojen määrittämisen tai osioiden piilottamisen.

#### Käyttö

```ts [content.config.ts]
// Icon
icon: property(z.string()).editor({ input: 'icon', iconLibraries: ['lucide', 'simple-icons'] })

// Media
image: property(z.string()).editor({ input: 'media' })
```

#### Vaihtoehdot

##### `input: 'media' | 'icon'`

Voit asettaa muokkaimen tuontityypin. Nykyisellään `icon` ja `media` ovat käytettävissä.

##### `iconLibraries: Array<string>`

Määritetään mitä [Iconify](https://icones.js.org/)-kirjastoja näytetään. Käytä tätä vaihtoehtoa kuvakekokoelmien suodattamiseen ja rajoittamiseen.

`hidden: Boolean`

Tätä vaihtoehtoa voidaan käyttää osioiden piilottamiseen muokkaimessa.

::tip
Muokkaimen tulot ovat täysin laajennettavissa. Voidaan luoda niin monta kuin halutaan, perustuen käyttäjien tarpeisiin.
::

## Koodimuokkain

Monaco-koodimuokkain tarjoaa täyden sisällön hallinnan, mahdollistaen raa'an sisällön kirjoittamisen suoraan:

MDC-syntaksi `Markdown`-tiedostoille tai `JSON` / `YAML`-syntaksi muille.
