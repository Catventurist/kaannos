🚀 Vapaan sanan alustan alkupolku on jännä, vaikea valita mitä rajata. Vuosikymmenten koodauskokemus kiteytettynä nykypäivän teknologiaan. Tarkoitus on tuoda esille piiloteltua tietoa useammalla kielellä.

Tavoitteena nopea ja helppokäyttöinen sovellus, jota ei noin vain kaadeta.

**Pääpiirteet:**

- ⚡ Nopea ja monipuolinen kokonaisuus
- 🔐 Tietoturva kunnossa
- 💳 Ei maksumuureja tai vastaavia
- 🎨 Tuore rakentelujärjestelmä
- 📱 Resoluutiolla tai laitteella ei väliä
- 📚 Laaja ja kasvava dokumentaatio
- 🗔 Studio sisällön luomiseen ja muokkaamiseen
- 🇫🇮 i18n Käännökset

**Tausta:** 🛠️

Ilmaista Avointa Lähdekoodia on vaikeaa voittaa vapaassa ideoiden ja teknologioiden markkinapaikassa. Jatkuvaa kehitystä, osien pohjautuessa samaan alustaan.

Alku voi olla kuoppainen maailmantilan ansiosta. Elämä voi muuttua silmänräpäyksessä, joten asioita on hankala lyödä lukkoon. ✨

## Muutokset

**nuxt.config.ts**
- devtools, telemetry: false
- studio
- i18n
- ui component css laskelmat
- custom
  - kuvakkeet
  - fontit

**.env**
- STUDIO_GITHUB_CLIENT_ID
- STUDIO_GITHUB_CLIENT_SECRET

**CLI**

- Studio: `bunx nuxi@latest module add nuxt-studio@alpha`
  - `bun i minimatch`
- Käännökset: `bunx nuxi@latest module add @nuxtjs/i18n`
